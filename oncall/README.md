## 值班規範

線上問題由值班人員處理 (包含上班期間)

## 值班津貼

NT$2,000

## 值班時間

星期一 00:00 ~ 星期天 23：59。如果是週日跨週一 00:00 以後發生的問題，則由下週值班人員處理

## 值班補休

若晚上 00:00 以後才處理完問題，隔天早上可以請公假補休，下午 1 點再進公司

## 值班輪替

一次輪一週，如當週有事請再提前提出進行班表調整，班表會同步給 HR 及客服以便值班津貼的發放和讓客服知道要找誰處理問題

## 線上問題聯絡順序

當週值班人員 → 直屬主管

## 其他事項

值班期間不需要一直在線上待命，只需注意 Skype 有無訊息及保持電話暢通，有問題能即時處理即可，如果家裡訊號不好請再提供其他即便是半夜也可聯絡到的方式(譬如 Line、Skype 等)

如果問題解決不了，可以轉來 Frontend 群組求救

[線上問題處理流程]

1. 至 gitlab 開立 issue 單，寫入問題描述，可以參照第一張圖
   ![](https://i.imgur.com/swfDFTc.png)

2. 在此 issue 單建立 MR，Source Branch 必須使用 PRD 開立分支 (這點要麻煩特別注意，目前 DEV Branch 跟 PRD Branch 有落差，千萬不能使用 DEV 分支)

3. 問題修完後，請至 MR 單寫下造成 Bug 的原因和修復方式，並將此單 Merge 回 PRD (若 commit 數量超過一次，merge 單時我會用 Squash commits，log 會比較乾淨)

4. 在本機 pull PRD 後，請先在本機確認問題已修復，再進行 Build Code、更新上 Production

5. 完成後請至 Production 驗證，確認沒問題後，到反應問題的群組回報修復完畢，等對方確認無誤後就完成了
